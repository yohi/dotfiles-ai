# Rules for Global Rules Directory

This directory contains project-wide coding standards and rules.
When editing or adding rules here:
1. Ensure files follow `markdownlint-cli2` standards (`MARKDOWN.md`).
2. Adhere to the documentation style defined in `DOCS_STYLE.md`.
3. Any changes affecting global agent behavior should be reflected in the master `AGENTS.global.md` at the root.
