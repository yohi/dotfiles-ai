# Claude Code / Claudia 使用ガイド

🤖 Claude Code のセットアップが完了しました！

## 🚀 使用方法
1. プロジェクトディレクトリに移動: `cd your-project-directory`
2. Claude Code を開始: `claude`

## 📋 初回セットアップコマンド
- `summarize this project`
- `/init`

## 🚀 SuperClaude (フレームワーク)
Claude Code内で以下のコマンドが利用可能:
- `/sc:implement <feature>`     - 機能実装
- `/sc:design <ui>`             - UI/UXデザイン
- `/sc:analyze <code>`          - コード分析
- `/sc:test <suite>`            - テストスイート
- `/sc:improve <code>`          - コード改善

## 🖥️ Claudia (GUI)
- **起動方法**: アプリケーションメニューから 'Claudia' を選択、または `/opt/claudia/claudia`
- **機能**: プロジェクト管理、使用状況分析、MCPサーバー管理等

## 🩺 トラブルシューティング
設定に不備があると感じた場合は、ターミナルで以下を実行してください。
```bash
make doctor
```
