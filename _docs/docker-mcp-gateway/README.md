# Docker MCP Toolkit & Gateway Documentation

**最終更新日: 2026年4月19日**

このディレクトリには、Docker MCP Toolkit および MCP Gateway に関するドキュメントが含まれています。

## 概要

**Docker MCP Toolkit** は、コンテナ化された Model Context Protocol (MCP) サーバーのセットアップ、管理、実行を容易にし、AI エージェントへの接続を可能にするツールセットです。

**MCP Gateway** は、複数の MCP サーバーをオーケストレートするためのオープンソースソリューションです。クライアントとサーバー間の集中プロキシとして機能し、構成、資格情報、アクセス制御を管理します。
